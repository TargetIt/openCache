## 未解决

- [ ] 覆盖率仍未达到高质量收敛水平。
  - 当前 Line `66.27%`，Branch `55.85%`。
  - 目标：后续至少把 branch coverage 提升到可接受门槛，并解释无法覆盖的代码。

- [ ] sector cache 状态组合仍需继续扩展。
  - 当前覆盖局部 sector miss、readable 关键路径、多 dirty sector writeback。
  - 后续需要覆盖 SECTOR_ASSOC/SECTOR_TEX_FIFO 的 multi-sector pending_read 组合。

- [ ] texture cache 极限路径仍需继续扩展。
  - 当前覆盖 miss pipeline、hit reserved、FIFO/ROB backpressure、result FIFO backpressure。
  - 后续需要覆盖 SECTOR_TEX_FIFO pending_read 和多请求返回顺序。

- [ ] MSHR 长 trace 和随机 differential/property 测试仍不足。
  - 当前有 fixed seed property trace。
  - 后续需要多 seed、长 trace、读写混合、与参考模型对照。

- [ ] set-index/hash golden 地址集还不够大。
  - 当前只校验选定地址。
  - 后续需要覆盖更多地址、不同 nset、边界地址和冲突模式。

- [ ] `llvm-cov` 报告中仍有 `20 functions have mismatched data` 警告。
  - 当前 `coverage.sh` 成功并输出报告。
  - 后续需要判断是多 binary profile 合并造成的可接受警告，还是需要拆分/调整覆盖率采集方式。

## 下一步优先级

1. 增加多 seed randomized/property 回归。
